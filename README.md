เกี่ยวกับการใช้ Ai แยกชนิดของขยะทั้ง 4 ประเภท(ขยะทั่วไป ขยะอันตราย แก้ว ขวด unknow) ตามรูปภาพ
โดยเก็บข้อมูลและทำการ Train Ai ด้วย TenserFlow และใช้ Flask มาช่วยเรียก API เพื่อทำเว็บไซต์ที่ใส่รูปเข้าไปแล้วให้Aiทำนายว่าเป็นขยะประเภทไหนกี่เปอร์เซ็น

เนื่องจาก TenserFlow มีขนาดใหญ่เกินไปจึงไม่สามารถหา host web ที่ไม่เสียค่าใช้จ่ายได้ จึงทำแบบ forward port ซึ่งถ้าไม่เปิดคอมทิ้งไว้ก็ไม่สามารถเข้าไปใช้งานได้
